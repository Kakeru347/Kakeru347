# 田辺 翔太 / Kakeru347

## 自己紹介

小売業の店舗業務を経験した後、バックオフィス系業務システムの開発・運用保守・改善・導入支援に携わっています。
チームリーダー兼システムエンジニアとして、要件整理から設計、開発、テスト、運用保守、利用者支援まで担当しています。

電子申請、経費精算、人事・労務系申請、データ連携などを中心に、現場の業務とシステムの両面を踏まえた対応を大切にしています。

## 主な担当業務

### 電子申請システムの開発・運用保守

人事・労務、経費精算、支払、稟議などの社内申請機能について、開発・改修、問い合わせ対応、障害・エラー調査を担当してきました。
申請内容や運用上の課題を確認し、改修の必要性を整理するとともに、関係部門との調整やチーム内の案件・対応状況の管理を行っています。

### 業務システムの導入支援・制度変更対応

経費精算システムの導入支援では、申請項目、費目、承認フロー、マスタの要件整理や、支払確定・会計連携・データ出力の確認を担当しています。
業務検討会の設計・進行、論点や確認事項の整理、利用者向け資料の作成にも携わっています。

また、インボイス制度、電子帳簿保存法、育児・介護関連制度などの変更に伴い、業務部門と確認しながら、申請項目・証憑・運用手順・利用者案内の見直しを支援してきました。

### データ・ファイル連携の運用

文書・取引データの連携基盤について、連携エラーの調査、残存ファイルや容量、処理条件の確認を担当してきました。
発生状況と調査結果を整理し、再実行方針の検討や、運用の見直しに向けた関係者との調整を行っています。

### 資料作成・利用者支援

会議資料、提案資料、マニュアル、クイックガイド、動画などを作成しています。
検討に必要な論点と、利用者が操作時に必要とする情報を分け、相手や用途に合わせて内容を整理しています。

## 仕事で大切にしていること

- **業務の背景を確認する**  
  制度や規程、現場の手順を確認し、申請項目やシステム設定だけでなく、実際の運用まで考えて対応します。
- **関係者の認識をそろえる**  
  利用者・業務部門・システム部門それぞれの事情を踏まえ、確認事項と判断が必要な点を明確にします。
- **継続して運用できる形にする**  
  問い合わせや障害への対応を、その場の解決だけで終わらせず、必要に応じて手順の見直しや資料の整備につなげます。
